# Modulación PSK   
Este repositorio contiene el desarrollo de un laboratorio enfocado en la implementación de un transmisor **M-PSK** (Modulación por Desplazamiento de Fase). 
El objetivo principal es diseñar y analizar un sistema de comunicación digital utilizando **GNURadio**, explorando conceptos clave como diagramas de constelación, efectos del ruido, parámetros de señal modulada y la estructura de bloques necesaria para su funcionamiento.  

A través de este laboratorio, se busca:  
- Generar una señal modulada en PSK mediante un **VCO** (Oscilador Controlado por Voltaje) en GNURadio, ya sea utilizando bloques predefinidos o algoritmos en Python.  
- Analizar el **diagrama de constelación** y su distorsión debido al ruido en el canal.  
- Evaluar parámetros fundamentales como **ancho de banda, eficiencia espectral y tasa de símbolos**.  
- Comprender la arquitectura de bloques en GNURadio para su aplicación en otros sistemas de comunicación.  
- Visualizar las señales de salida tanto en **radiofrecuencia (RF)** como en **frecuencia intermedia (FI)**.
