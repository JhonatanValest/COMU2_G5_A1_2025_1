# COMU2_G5_A1_2025_1
# Laboratorio 5: Modulación M-QAM y Análisis de BER

## Descripción
Este repositorio contiene los resultados y códigos del laboratorio de Comunicaciones II sobre modulación digital, enfocado en técnicas M-QAM (BPSK, QPSK, 8-PSK y 16-QAM). Se analizó el impacto del ruido AWGN en las constelaciones, espectros y tasa de errores (BER), comparando los resultados experimentales con los teóricos.

## Objetivos
1. Implementar modulaciones digitales en GNU Radio.
2. Analizar constelaciones y espectros con/sin ruido.
